# Decision log

Record every deviation from the design docs here (newest first): date, what changed, why.

| Date | Decision | Why |
|---|---|---|
| 2026-11-25 | `API_BASE_URL` reverted to `https://api.anthropic.com` for the public release. | The router URL was for the author's local demo only (see the entry below). |
| 2026-10-10 | **DEMO ONLY:** optional built-in API key via `VITE_EMBEDDED_API_KEY` in a git-ignored `.env.local`, resolved in `background/apiKey.ts` (a key entered in Settings wins). Only the service worker bundle contains it (verified); `npm run zip` refuses to package a build that contains it; new `KEY_SOURCE` message lets the popup say "built-in demo key". | Requested by the author so demo users don't have to enter a key. A key shipped inside an extension is readable by anyone who has it, so it must stay out of source/docs/git and out of any shared zip. **Revoke/rotate the key after the demo.** |
| 2026-10-10 | **DEMO ONLY:** `API_BASE_URL` in `src/shared/apiConfig.ts` is `https://api.routerplus.com` (the router the author's key belongs to, confirmed by the author); the manifest host permission and the Settings privacy note derive from it. **Revert to `https://api.anthropic.com` before sharing or publishing.** | A key from the router is rejected by api.anthropic.com (401). A single constant keeps the swap one line. Untested assumption: the router accepts `/v1/messages`, the listed model ids and `output_config` structured outputs. |
| 2026-10-10 | Claude calls use `max_tokens: 4096` (design said 1024), `maxRetries: 1`, a 30 s timeout, and an explicit `baseURL: https://api.anthropic.com`. | Adaptive-thinking tokens count toward `max_tokens`, so 1024 risked truncated answers; the explicit base URL guarantees the key only goes to Anthropic (the SDK would otherwise honour an `ANTHROPIC_BASE_URL` env var). |
| 2026-10-10 | `llmService` imports Zod from `zod/v4` (shipped inside zod 3.25). | The SDK's `zodOutputFormat` is typed against `zod/v4`. |
| 2026-10-10 | `TEST_KEY` accepts an optional `apiKey`. | Lets the popup test a typed key before saving it. |
| 2026-10-10 | Smart pause: hover-pause suppression after a manual play is also cleared when the pointer leaves the captions (not only on the next card open). | Otherwise hover-pause would stay off until the next lookup, which feels broken. |
| 2026-10-10 | Netflix selectors in `siteAdapters.ts` verified on a real title by the user (highlight, click, card, pause/resume all work). | M5 acceptance. |
| 2026-10-10 | Added `HAS_KEY` and `OPEN_SETTINGS` background messages. | Content scripts must learn whether AI Mode is on without ever receiving the key; the card's "Add an AI key" nudge needs a way to open the popup (stores `popupTab: 'settings'`, then `chrome.action.openPopup()`; falls back to a toast hint). |
| 2026-10-10 | Extra files: `background/router.ts` (handler logic; `index.ts` only registers listeners), `content/captionController.ts`, `content/cardController.ts`, `content/cardContent.ts`, `content/dom.ts`, `content/captionHistory.ts`. | Keeps modules small and unit-testable without registering Chrome listeners on import. |
| 2026-10-10 | When the card is placed above a word it is anchored by its bottom edge, so it grows **upward**. 03 §4.3 said "grow downward only". | Growing downward from an above placement would cover the word being explained. |
| 2026-10-10 | The "Paused for lookup" toast sits 80px above the bottom of the player rather than a 16px inset. | A 16px inset would overlap the player's control bar, which 03 forbids elsewhere. |
| 2026-10-10 | Idiom badge in Free Mode reads `B2+` (no `est.` prefix). | Matches 03 §4.2; the "+" already signals an approximate level. |
| 2026-10-10 | Idiom matcher tries the first token as written plus every base-form candidate (`lemmaCandidates`), instead of a single lemma. | The single-guess rule turned "giving" into "giv", so "giving up" would not match "give up". |
| 2026-10-10 | Idiom list has ~370 entries (invariant widened from 250–350 to 250–400); removed very common phrases ("a lot of", "of course", "such as", "kind of", etc.). | More coverage is better for learners, but underlining ultra-common phrases would clutter captions. |
| 2026-10-10 | `wordFrequency.ts` comes from `google-10000-english` 20k list, whose README does not recommend commercial use without an LDC licence. | Fine for the personal demo; **re-check or replace the list before any Web Store release.** |
| 2026-10-10 | Tailwind config is `tailwind.config.ts` (not `.js`). | It imports the typed design tokens from `src/shared/tokens.ts`, so tokens stay defined in one place. |
| 2026-10-10 | Dependency versions pinned to the stack in 04 §1: Vite 6.4, `@crxjs/vite-plugin` 2.7, React 18, Tailwind 3.4, Vitest 2.1, TypeScript 5.9, Zod 3.25, `@anthropic-ai/sdk` 0.133. | Newer majors exist (Vite 8, crxjs 3, React 19, Tailwind 4, Zod 4, TS 7) but were not evaluated; the pinned set is known to work together. |
| 2026-10-10 | Planning docs created (01–06). Hybrid definition source: Free Mode (dictionaryapi.dev + idiom list + frequency level) with optional Anthropic AI Mode; demo via load-unpacked. | Agreed with the user before development. |
| 2026-10-10 | `tests/setup.ts` stubs `VITE_EMBEDDED_API_KEY` to empty before every test. | Vitest loads `.env.local`, so the demo key leaked into the "no key" router tests and made 4 fail. Tests must not depend on a local env file. |
| 2026-10-10 | Speed: default AI model is now Haiku 5.5 (spec said Opus); `EXPLAIN` is sent in parallel with `HAS_KEY` (a `NO_KEY` answer falls back to Free Mode); the card prefetches `EXPLAIN` after the pointer rests 150 ms on a caption word, and the click reuses the in-flight/cached request. | Users reported long waits. Opus was the slowest model and the lookups ran one after another. Prefetch spends API calls on words that are hovered but never clicked. Users who already saved a model keep it until they change it in Settings. |
| 2026-10-10 | `CaptionController` now polls for the player for as long as it runs, re-attaches if the site replaces the player element, and falls back to the page's `<video>` ancestor when the player selectors don't match; added `.watch-video` and `[data-uia="player-timedtext"]` to the Netflix selectors. | Netflix is a single-page app that recreates the player (e.g. on episode change); the old code gave up after 30 s and never re-attached. |
